# MILOOP — Connect. Share. Belong.

A responsive social-networking front-end prototype built with HTML, CSS, and vanilla JavaScript.

## First milestone
- Premium blue-and-white responsive home feed
- Story strip, trending topics, and suggested people
- Create-post dialog and in-page post publishing
- Like interactions, search, and feed sorting
- Responsive mobile navigation

## Current limitations
This is a **front-end prototype**, not a live social network yet. Demo posts are held in browser memory and disappear on refresh. Authentication, database persistence, media uploads, messaging, notifications, and moderation tools are not connected yet.

## Run
Open `index.html` in a browser, or publish the repository with GitHub Pages.

## Roadmap
1. Connect Firebase Authentication and user profiles.
2. Add Firestore-backed posts, comments, likes, and follows.
3. Add Firebase Storage for safe photo/video uploads.
4. Implement stories, messaging, and notifications.
5. Add reporting, blocking, moderation, and admin tools.
6. Review Firestore and Storage security rules before public launch.

Never put service-account credentials or private server secrets in client-side code.
